# Malatang Price Guessing Game

A Python coursework project 

- Currency: RMB (¥)
- All ingredients share one shop price per 50g.
- Each ingredient selection receives a hidden variable weight.
- Players must include all required ingredients.
- The checkout reveals the total weight, actual price, and score.
- The score rewards closeness to the target budget; missing required ingredients incur a penalty.
